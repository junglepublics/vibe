Tips

Force a colour yourself: put a rule's tag, like #recreation or #events, in an event's title or description. It beats every keyword and guest rule. Tags are shown on each rule below.
Words match whole words only:lunch matches “Lunch with Sam” but not “Launchpad”. Separate words with a comma or Enter.
Add #exception to an event's description to skip every rule for that event (Lunch still applies).
“None” leaves the event in your calendar's own colour.

Exceptions

Events you've overridden by hand: ones with #exception (no keyword rules apply) or a rule's tag such as #recreation (that rule's colour is forced), in the title or description.

Lunch

Every weekday gets a one-hour lunch. If a day already has a lunch event, for example a shared lunch, no extra block is added. The colour is set by the Lunch rule under Colour rules.
